# 0002. Java 21 toolchain and bytecode

- Status: Accepted
- Date: 2026-10-14

## Context
Paper 1.21.11 runs on Java 21; Paper 26.x requires Java 25 but loads Java 21 bytecode.

## Decision
Compile with a Java 21 toolchain and `--release 21`. Gradle daemon also runs on 21
(`gradle/gradle-daemon-jvm.properties`). Java 25 is used only as the runtime for 26.x servers.

## Consequences
No Java 22+ language/API features. Revisit when 1.21.11 support is dropped.
